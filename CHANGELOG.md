# Changelog

## [1.0.0] - 2025-05-18

### Added
- Multi-threaded download engine with parallel streams
- Smart queue management with bandwidth limits and scheduling
- Browser extension for Chrome, Edge, Brave with auto-intercept
- Cyber-Industrial UI design with multiple themes (Cyber Dark, Terminal, OLED Black, Deep Ocean)
- Cross-platform support: Windows, macOS, Linux, Android
- System tray integration with auto-start on boot
- Zero telemetry — fully offline, no analytics
- HLS/m3u8 streaming download support

### Platforms
- Windows: .exe installer (Inno Setup), portable
- macOS: .dmg installer (Intel & Apple Silicon)
- Linux: .deb package, .AppImage
- Android: APK sideload
