# Project Flow: Rust Native Download Manager

Chào mừng bạn đến với kho lưu trữ kế hoạch và lộ trình phát triển cho dự án **Rust Native Download Manager**.

## 📌 Tổng quan
Đây là nơi lưu trữ các tài liệu phân tích, kế hoạch chi tiết và lộ trình phát triển cho ứng dụng trình quản lý tải xuống thế hệ mới, được xây dựng bằng Rust với mục tiêu tối ưu hóa hiệu suất và trải nghiệm người dùng.

## 📂 Nội dung chính
- [**Kế hoạch chi tiết (Project Plan)**](project_plan.md): Chứa lộ trình 4 giai đoạn, kiến trúc kỹ thuật (Slint, SQLite, Native Messaging) và các tiêu chuẩn phát triển.

## 🚀 Mục tiêu chính
1. **Hiệu năng cao**: Tận dụng tối đa sức mạnh của Rust.
2. **Siêu nhẹ**: Ứng dụng chạy native, tốn cực ít RAM và CPU.
3. **Tích hợp sâu**: Kết nối mượt mà với trình duyệt qua Native Messaging API.
4. **Giao diện hiện đại**: Sử dụng Slint Framework để vẽ UI bằng GPU.
