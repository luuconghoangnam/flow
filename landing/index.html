Browser Extension

Capture any download
with one hover.

The moment you hover over a download link, a tiny Flow button appears. Click it — the browser's save dialog never shows. The download goes straight to Flow. Large files are intercepted automatically.

  • ✓ Auto-intercepts files >1MB
  • ✓ Works with Chrome, Edge, Brave
  • ✓ Neon overlay button — no UI clutter
  • ✓ Toggle on/off from popup
  • ✓ Sends to Flow via localhost:15151

FAQ

Common questions.

Yes. Flow is 100% free, open source under Apache 2.0. No premium tier, no ads, no subscriptions — ever.
Zero telemetry. Flow never phones home. All data stays on your device. You can verify this in the source code.
The extension communicates with the Flow desktop app via a local HTTP server on port 15151. When you click the Flow button on a link, it sends the URL to the app which opens the download dialog.
Yes. You can paste URLs directly into Flow, or use the "New Download" button. The extension just makes it faster.
Yes. Flow supports HLS (m3u8) streams in addition to standard HTTP/HTTPS downloads.
Flow registers itself in Windows startup automatically after installation. It starts silently in the system tray. You can toggle this in Settings → General → Auto-start on boot.
